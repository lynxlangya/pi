## 注释约定

- `// 注：`：我加的解释（为什么这样写、举例、可跳过的提示）。
- `// 译：` / `* 译：`：紧跟在英文原注释下面的中文翻译。
- 写着"可跳过"的地方，第一遍不读。
- 已用 esbuild 去注释后与 HEAD 对比，14 个文件都确认只改了注释，代码一个字符没动。

## 一条请求的全链路（先记住这张图再读代码）

```
models.stream(model, context)                 models.ts        Models 层：找 provider、解析认证、合并请求头
  └─ lazyStream(...)                          api/lazy.ts      同步返回流，后台做异步准备，失败转 error 事件
       └─ provider.stream()                   models.ts        createProvider 组装出的 Provider
            └─ openAICompletionsApi()         lazy.ts          首次调用才 import openai-completions.ts
                 └─ stream(model, ctx, opts)  api/openai-completions.ts
                      ├─ transformMessages    api/transform-messages.ts  跨 provider 清洗历史
                      ├─ buildParams          请求体 + 各家思考参数（compat）
                      ├─ retryProviderRequest utils/provider-retry.ts    HTTP 层重试
                      └─ for await chunk → push(text_delta / toolcall_delta / ...) → done | error
                                              utils/event-stream.ts      事件队列
```
