# pi 界面学习课程：从界面往里学

> 在 pi 的 TUI 里，一课只做一个操作，回答一个问题，最多读一两个函数。代码位置见 [回车到屏幕链路](./pi-回车到屏幕链路-261109.md)。
> 行号基于 `feat/learn` 分支（2026-11-09）。对不上时，搜索表里给出的函数名。

## 每一课的 5 步

1. **看现象**：做一个操作，盯住屏幕上的一个变化。
2. **先猜**：写一句"我猜它是怎么做到的"。
3. **看数据**：先看会话文件（`/session` 能找到路径）、json 事件流或调试脚本的 jsonl。
4. **数据答不了再读代码**：只读表里给出的那一两个函数。
5. **记一句话**：填进每张表最后的"结论"列。

一个晚上做一级就够了。`/login`、`/share`、`/bug`、`/import` 这类命令先跳过，它们和理解 Agent 的原理无关。

## 第 0 级：看懂这一屏（10 分钟，不读代码）

| 位置 | 看到的 | 含义 |
|---|---|---|
| 顶部 | `[Context] [Skills] [Prompts] [Extensions]` | 启动时加载的资源。Context 拼进系统提示词；Skills 先只加载描述，用到才读全文；Prompts 是 `/cl` 这类模板，在 `.pi/prompts/`；Extensions 在 `.pi/extensions/` |
| 编辑框 | 边框颜色 | 表示思考级别，红色是 `max`。输入 `!` 进入 bash 模式时会变色。逻辑在 `interactive-mode.ts` 的 `updateEditorBorderColor` |
| 底部左 | `0.0%/1.0M (auto)` | 上下文已用比例 / 模型上下文窗口；`(auto)` 表示开了自动压缩。在 `components/footer.ts` |
| 底部右 | `(deepseek) deepseek-flash • max` | 供应商、模型、思考级别 |

动手：按 `ctrl+o` 看完整的启动信息和已加载资源；输入 `/hotkeys` 看全部快捷键。

### 示例：第 1 课完整走一遍

1. **看现象**：`/model` 弹出列表，选中一项后，底部右侧变了。
2. **先猜**：列表是写死在代码里的吗？切换存在哪里？
3. **看数据**：`/session` 找到会话文件，打开它，找 `"type":"model_change"` 那一行。
4. **读代码**：`showModelSelector` 负责界面，`setModel` 负责改状态并写进会话文件。
5. **记一句话**：填进上表的"结论"列。
